# Roadmap

VerdinCore is actively developed in a private repository. This roadmap communicates direction, not fixed release dates or contractual commitments.

## Current foundation

The current core includes:

- multi-brand configuration and theme selection;
- hierarchical pages and post publishing;
- topics and topic groups;
- reusable structured blocks;
- managed image uploads and variants;
- a protected administrative dashboard;
- scheduled publishing and maintenance;
- metadata, Schema.org, RSS, sitemaps, and robots support;
- first-party visitor and content analytics;
- production page caching;
- optional public GitHub repository synchronization;
- automated tests for central application services.

## Near-term priorities

The immediate public-repository priorities are:

- keep architecture and feature documentation aligned with the private core;
- document product decisions and important architectural tradeoffs;
- add clearer visual examples of administration and publishing workflows;
- publish release notes or milestone summaries when the release process is formalized;
- define a private channel for responsible security reporting.

## Product direction

Areas under consideration include:

- a broader library of reusable blocks and composition patterns;
- richer editorial workflow and revision history;
- improved media search, reuse, and lifecycle visibility;
- stronger accessibility checks in authoring workflows;
- expanded APIs and integration boundaries;
- more deployment and operational automation;
- additional themes and brand-level presentation options;
- deeper performance and content-quality reporting;
- AI-assisted workflows with explicit editorial control.

Items in this section are exploratory. They are not available features until moved into the documented current foundation.

## How this roadmap is maintained

The roadmap favors outcomes over speculative version numbers. When a capability is implemented and verified in the private core, it moves to the feature and architecture documentation. Planned work remains clearly labeled until then.
