# Roadmap

VerdinCore is developed privately. This roadmap records direction, not release dates or contractual commitments.

## Current foundation

Version `4.0.1` provides the publishing, taxonomy, blocks, media, multi-brand, authentication, analytics, SEO, caching, and maintenance capabilities listed in the [feature map](features.md).

## Documentation priorities

- Keep public documentation aligned with verified application releases.
- Add release notes when the private release process is formalized.
- Add administration screenshots and short workflow examples.
- Establish a private channel for responsible security reports.

## Product direction

The following areas are under consideration:

- revision history and a richer editorial review flow;
- stronger media search, reuse, and lifecycle visibility;
- authoring-time accessibility checks;
- clearer API and integration boundaries;
- more deployment automation;
- additional themes and reusable block patterns;
- deeper performance and content-quality reporting;
- assisted editorial tools with explicit human approval.

These items are not current features. A capability moves into the main documentation only after it exists in the application and has been checked against the code and tests.

## Maintenance rule

The roadmap describes outcomes rather than speculative version numbers. When priorities change, current functionality remains documented separately so readers can distinguish the product they can use today from possible future work.
